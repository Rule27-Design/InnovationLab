03Tooltip & popover

Tooltips are pure CSS via a data-tip attribute. The popover uses the native Popover API - light-dismiss for free - anchored to its trigger with CSS anchor positioning where supported.

Native popover

No JavaScript: popovertarget wires the button, the browser handles focus, stacking, and click-outside dismissal.

04Dialog & command palette

Native <dialog> with a blurred ::backdrop - focus trapping and Esc-to-close come from the browser. The palette is the same element dressed as a ⌘K launcher with live filtering.
